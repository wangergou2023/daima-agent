# I2C Tools

## 决策树

```
用户想要什么？
├─ 看看有哪些 I2C 总线        → i2cdetect -l
├─ 扫描某条总线上的设备         → i2cdetect -y <总线号>
├─ 读某个设备的单个寄存器       → i2cget -y <总线> <地址> <寄存器>
├─ 写某个设备的寄存器           → i2cset -y <总线> <地址> <寄存器> <值>
├─ 导出设备所有寄存器           → i2cdump -y <总线> <地址>
├─ 不知道设备地址               → 先 i2cdetect -y 扫描
└─ 高级读写（组合传输）         → i2ctransfer -y <总线> ...
```

## 命令速查

所有操作用 `terminal` 工具执行。

| 命令 | 用途 | 示例 |
|------|------|------|
| `i2cdetect -l` | 列出所有 I2C 总线 | |
| `i2cdetect -y 1` | 扫描总线 1 上的设备 | |
| `i2cget -y 1 0x50 0x00` | 读总线1、地址0x50、寄存器0x00 | |
| `i2cset -y 1 0x50 0x00 0xFF` | 写寄存器 | |
| `i2cdump -y 1 0x50` | 导出设备所有寄存器 | |

## 示例

**扫描 I2C-1 总线：**
```bash
# 输出中数字 = 设备地址（7位），-- = 空，UU = 内核占用
i2cdetect -y 1
```

**读温度传感器（常见地址 0x48）：**
```bash
i2cget -y 1 0x48 0x00
```

**写 LED 驱动寄存器（地址 0x50）：**
```bash
i2cset -y 1 0x50 0x01 0xFF
```

## 注意事项
- 需要 root 时用 sudo；Web 终端支持交互输入密码
- 设备地址为 7 位地址（不含读写位），i2cdetect 输出已显示 7 位
- `-y` 跳过确认提示，脚本中必须加
- `--` = 无设备，`UU` = 内核驱动占用
- 写寄存器前确认芯片手册，误写可能损坏硬件
