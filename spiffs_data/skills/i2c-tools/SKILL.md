# I2C 工具

使用 `i2c-tools` 命令检测和操作 Linux I2C 总线及设备。所有操作都使用 `terminal` 执行。

## 何时使用

- 用户要查看有哪些 I2C 总线或设备。
- 用户要读取或写入某个 I2C 设备寄存器。
- 用户要导出寄存器表或调试 I2C 连接。

## 使用步骤

1. 查看总线：`i2cdetect -l`。
2. 不知道设备地址时先扫描：`i2cdetect -y <bus>`。
3. 读寄存器：`i2cget -y <bus> <addr> <reg>`。
4. 写寄存器：`i2cset -y <bus> <addr> <reg> <value>`。
5. 导出寄存器：`i2cdump -y <bus> <addr>`。
6. 高级组合传输时使用 `i2ctransfer -y <bus> ...`。

## 工具与路径

- 常用工具：`terminal`。
- 常用命令：`i2cdetect`、`i2cget`、`i2cset`、`i2cdump`、`i2ctransfer`。
- `i2cdetect` 输出中，数字表示设备地址，`--` 表示无设备，`UU` 表示内核驱动占用。

## 输出要求

- 说明总线号、设备地址和寄存器含义。
- 读操作给出原始值；必要时再解释换算结果。

## 注意事项

- 设备地址为 7 位地址，不含读写位。
- 脚本中必须加 `-y` 跳过交互确认。
- 写寄存器前确认芯片手册，误写可能损坏设备。
- 看到 `UU` 时不要强行读写，先确认内核驱动占用情况。
