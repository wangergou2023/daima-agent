# 天气

通过 `weather` 工具获取当前天气、未来几天预报或逐小时天气摘要。

## 何时使用

- 用户询问天气、温度、降雨、体感、风力、湿度。
- 用户询问未来几天预报。
- 用户询问今晚、未来几个小时、几点下雨等逐小时问题。

## 使用步骤

1. 使用 `get_current_time` 获取当前日期。
2. 优先使用用户给出的城市名；中文和英文一般都可用。
3. 当前天气调用 `weather {"location":"北京","type":"current"}`。
4. 多日预报调用 `weather {"location":"北京","type":"forecast","days":3}`。
5. 逐小时天气调用 `weather {"location":"北京","type":"hourly"}`。
6. 如果用户没有给地点，可以省略 `location`，让服务按 IP 自动定位。

## 工具与路径

- 常用工具：`get_current_time`、`weather`。
- 常用参数：`location`、`type`、`days`、`adcode`。

## 输出要求

- 当前天气给出天气现象、温度、体感、风力或湿度中的关键项。
- 预报类问题按天或时间段简洁列出。

## 注意事项

- 用户给了明确城市时，不要默认按 IP 定位。
- 用户问“未来几天”时显式使用 forecast/days。
- 用户问“今晚几点下雨”或“未来几个小时”时优先使用 hourly。
- 用户给行政区编码时可用 adcode 查询。
