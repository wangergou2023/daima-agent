# 每日简报

为用户生成简洁、实用的每日简报，适合作为早报、今日提醒或定时推送内容。

## 何时使用
当用户要求每日简报、早报或“今天安排/提醒是什么”。
也适合作为 heartbeat/cron 任务。

## 使用步骤
1. 用 get_current_time 获取今天日期
2. 读取 /spiffs/memory/MEMORY.md 获取用户偏好与上下文
3. 读取今日笔记（若存在）
4. 若 USER.md 中有地点，用 weather 获取天气
5. 调用 cron_list 获取定时任务
6. 汇总记忆中的待办事项与今日计划
7. 如果用户问项目进展、周报或今日工作，读取 /spiffs/memory/PROGRESS.md，并优先按 `progress-tracker` 的口径整理
8. 输出简洁简报，包含：
   - 日期与时间
   - 天气（若 USER.md 有地点）
   - 记忆中的待办事项
   - 已安排的 cron 任务
   - 今日项目进展或临近 deadline（若有）

## 格式
保持简短——最多 5-10 条要点，使用用户偏好语言。

## 注意事项
- 如果天气返回内容较长，要主动压缩成 1-3 行重点
- 如果没有今日笔记或定时任务，直接跳过，不要硬编内容
- 如果用户要“更简短”版本，优先保留日期、天气、待办、提醒这几项
