# 系统信息

获取系统状态并做简短摘要，默认只执行查看类命令。

## 何时使用

- 用户要求查看 dmesg、内核版本、内存占用、系统负载、磁盘使用情况。
- 用户要确认进程、端口、设备或系统运行状态。

## 使用步骤

1. 判断用户要看的系统信息类型。
2. 使用 `terminal {"command":"<shell 命令>","timeout":120}` 执行只读命令。
3. 输出时摘要关键指标，避免整屏刷屏。
4. 如果命令可能较慢，如包管理、扫描、大日志，主动调长 timeout。

## 工具与路径

- 常用工具：`terminal`。
- 常用命令：`uname -a`、`df -h`、`free -h`、`uptime`、`ps`、`dmesg`、`ip addr`。

## 输出要求

- 先给摘要，再按需附关键原始行。
- 数值类信息尽量保留单位。

## 注意事项

- 用户只是“查看信息”时不要执行写操作。
- 输出太长时优先总结关键指标。
- 需要 root 权限或高风险命令时先说明影响。
