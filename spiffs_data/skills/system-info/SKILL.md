# 系统信息

获取内核、内存、负载、磁盘、进程等系统状态信息，并做简短摘要。

## 何时使用
当用户要求查看 dmesg、内核版本、内存占用、系统负载、磁盘使用情况等。

## 使用步骤
1. 直接调用工具执行系统命令。
2. 优先使用 `terminal {"command":"<shell 命令>","timeout":120}`
3. 输出时做简短摘要，避免整屏刷屏。
4. 如果命令可能较慢（如包管理、扫描、日志较大），主动把 timeout 调长。

## 示例
用户：“看一下内核信息”
→ terminal {"command":"uname -a","timeout":120}
→ “内核版本：... 架构：...”

用户：“看一下磁盘和内存”
→ terminal {"command":"df -h && free -h","timeout":120}
→ “磁盘主要分区剩余 ...，内存已用 ...”

## 注意事项
- 不要默认执行高风险写操作；用户只是“查看信息”时，应只读
- 输出太长时优先总结关键指标，而不是整段原样贴出
